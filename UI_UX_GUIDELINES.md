# UI_UX_GUIDELINES.md

## Design Philosophy

LearnFootball should feel:

* Educational
* Modern
* Interactive
* Approachable
* Premium

Users should never feel overwhelmed.

# Animation Principles

Animations should teach.

Good Examples:

* Position movement
* Formation changes
* Tactical transitions

Bad Examples:

* Decorative spinning elements
* Long loading screens

# Academy Pages

Every lesson must contain:

1. Concept
2. Visual Diagram
3. Beginner Explanation
4. Advanced Explanation
5. Examples
6. Quiz

---

# Mobile Experience

Target Widths:

* 320px
* 375px
* 768px

Navigation should collapse into a bottom sheet menu.

---

# Cursor

Custom football cursor.

Requirements:

* Lightweight
* Smooth
* Disable on touch devices

---

# Accessibility

Must support:

* Keyboard Navigation
* Screen Readers
* Reduced Motion
* High Contrast Mode
